Prepared for instant, zero-configuration deployment on **Vercel**.

## 🚀 Live Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript 5

## 🛠️ Local Development

### 1. Prerequisites
Ensure you have Node.js 18.17+ or newer installed.

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for Production
```bash
npm run build
```

## 🌐 How to Deploy on Vercel (Zero Config)

### Option A: Via GitHub (Recommended)

1. **Initialize Git & Push to GitHub:**
   ```bash
   git init
   git add .
   git commit -m "feat: complete firoz khan portfolio"
   git branch -M main
   # Add your remote repo:
   git remote add origin https://github.com/your-username/firoz-khan-portfolio.git
   git push -u origin main
   ```

2. **Import into Vercel:**
   - Go to [vercel.com](https://vercel.com) and log in.
   - Click **"Add New..."** → **"Project"**.
   - Select your GitHub repository (`firoz-khan-portfolio`).
   - Framework Preset will automatically detect **Next.js**.
   - Root Directory: `./` (leave default).
   - Click **"Deploy"**.

3. **Domain Configuration:**
   - Once deployed, go to **Settings** → **Domains** on Vercel to attach your custom domain (e.g., `firozkhan.dev` or `firoz.fkdigitalmedia.com`).

---

### Option B: Via Vercel CLI

1. Install the Vercel CLI globally:
   ```bash
   npm i -g vercel
   ```

2. Run the deploy command from the project root:
   ```bash
   vercel
   ```

3. Deploy to production:
   ```bash
   vercel --prod
   ```
